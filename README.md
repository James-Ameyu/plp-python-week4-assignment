# PLP Python Week 4 - Functions

This project practices Python functions, parameters, return values, and default parameter values.

## Files

### welcome.py

Contains a `welcome()` function that accepts a person's name and returns a welcome message.

### toolbox.py

Contains three functions: `double()` doubles a number, `is_pass()` checks whether a score is 50 or higher, and `greet()` creates a greeting using a default or custom greeting.

## Hardest Function

The `greet()` function was the hardest to write because it uses a default parameter. I had to understand how the function can use `"Hello"` automatically when no greeting is provided and use a different greeting when one is supplied.
